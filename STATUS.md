## How the whole thing works

Five sources are scraped into local JSON, then joined by one query tool.

```
  Serebii ─────────┐
  pokebase.app ────┤
  pokedata.ovh ────┼──► data/raw/  (cached HTML+JSON, regenerable, not in git)
  PokeAPI ─────────┤          │
  Smogon ──────────┤          ▼
  Smogon calc ─────┘   (the executable one: the engine and its sets)
                       build_db.py / fetch_*.py
                              │
                    data/db/    (rules: what exists, what it does)
                    data/meta/  (metagame: what people actually run)
                              │
                              ▼
                        scripts/query.py  ◄── scripts/ledger.py (what HE owns,
                              │                read from the Supabase ledger)
                              ▼
                        tracker/  (the app on his phone, rebuilt from data/db)
```

Nothing is answered from general Pokemon knowledge. Champions rebalances moves,
so console-game numbers are wrong here; every figure comes from a
Champions-specific source. `CLAUDE.md` holds what applies to every session; the
game rules are in the `champions-rules` skill and the rules for each part of
the code in `.claude/rules/` (`.claude/rules/docs.md` has the map).

### The scripts

| Script | Does |
|---|---|
| `fetch_serebii.py` | Dex, movedex, rules pages (the ground truth) |
| `build_db.py` | Turns that HTML into `data/db/*.json` |
| `fetch_pokebase.py` | Ladder usage + speed tiers |
| `fetch_pokebase_splits.py` | Per-Pokemon moves, items, spreads, teammates |
| `fetch_smogon.py` | Written VGC analyses (VGC formats only) |
| `fetch_smogon_calc.py` | Smogon's Champions damage engine (`--check` for drift) |
| `smogon_engine.js` | Runs that engine locally; `damage.py` asks it |
| `fetch_tournament.py` | Worlds standings + full teamlists |
| `query.py` | Every lookup — the only thing you normally run |
| `damage.py` | The damage calculator, local or through Smogon's engine |
| `ledger.py` | Reads his box, builds and teams from Supabase |
| `refresh.py` | The whole pipeline, source to app, in order |
| `daily.py` | The gate: every check, then the build |
| `build_typechart.py` | Type chart + natures, cross-checked against Serebii |
| `audit_forms.py` | Checks no form/gender/Mega went missing |
| `test_norm.py` | Checks names match across the five sources |

Those are the ones a session reaches for. Every script, by family, is in
`docs/ARCHITECTURE.md` §6, and §14 there goes from a symptom to the file
behind it.

### Everyday commands

```bash
python scripts/query.py brief <pokemon>     # dossier: all sources at once
python scripts/query.py build [pokemon]     # his builds, rule-checked
python scripts/query.py megas               # what he can actually field
python scripts/query.py owned               # his box vs the meta
python scripts/query.py usage --top 30
python scripts/query.py worlds --usage --top 64
python scripts/query.py worlds --usage --division all   # Masters/Seniors/Juniors
python scripts/query.py moves --flag sound
python scripts/query.py moves --effect "protects itself" --learners
python scripts/query.py counter-priority
python scripts/query.py speed --min 100
```

## Where it stands

- **The refresh runs itself.** Every night GitHub Actions refreshes the sources,
  runs the gate and opens a PR that merges itself; the merge deploys the app.
- **The sources all agree on the roster.** Every form in our dex matches a
  pokebase entry, and Smogon's engine now covers the M-C species that it could
  not calculate on launch day.
- **The source disputes are settled.** Each decided number and its reason live
  in `build_db.MOVE_RULINGS` (Night Slash 16 PP; Freeze-Dry has no freeze).
- **His state is not written down here.** The box, HOME, stones, items, builds
  and teams live in the app; `scripts/ledger.py` reads them.
